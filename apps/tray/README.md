# Coriven Tray App

A Tauri v2 thin-shell desktop tray application for Coriven. Runs as a background tray icon — no primary window. All business logic lives in the backend API.

**Thin-shell constraint (ADR-003, §13.2):** This app contains no database client, no Supabase data access, no recurrence math, and no business logic. Any addition that violates this is a review-gate failure.

---

## Prerequisites

- **Rust toolchain:** 1.77.2 or later (installed as `x86_64-pc-windows-msvc`)
  - Install: https://rustup.rs
  - On this machine Rust is installed but NOT on the shell PATH. Use full paths:
    - `~/.cargo/bin/cargo` (Git Bash) or `$HOME\.cargo\bin\cargo` (PowerShell)
  - Verify: `~/.cargo/bin/rustc --version` → `rustc 1.77.2` or later
- **Node.js / npm:** Already on PATH (used for the Tauri CLI wrapper)
- **WebView2 Runtime (Windows):** Pre-installed on Windows 10 1803+ and Windows 11
- **MSVC Build Tools:** Required by the `x86_64-pc-windows-msvc` Rust target
  - Install via Visual Studio Installer → "Desktop development with C++"

## Development

```bash
# From the repo root — install all npm dependencies (includes @tauri-apps/cli)
npm install

# Start the tray app in dev mode (Rust hot-recompile, webview dev server)
npm run tray:dev
# OR from apps/tray directly:
cd apps/tray && npx tauri dev
```

> Note: `tauri dev` triggers a Rust rebuild on first run. Subsequent rebuilds are incremental.
> If cargo is not on PATH, the Tauri CLI finds it automatically via `~/.cargo/bin/cargo`.

### Web app URL (dev)

By default the **Open App** tray menu item opens `http://localhost:3000`.
To override, set the environment variable before launching:

```bash
CORIVEN_WEB_URL=https://your-preview.vercel.app npm run tray:dev
```

## Building (unsigned Windows executable)

```bash
# From the repo root
npm run tray:build
# OR build the Rust binary directly (debug):
cd apps/tray/src-tauri && ~/.cargo/bin/cargo build
# Release binary:
cd apps/tray/src-tauri && ~/.cargo/bin/cargo build --release
```

The debug binary lands at:
```
apps/tray/src-tauri/target/debug/coriven-tray.exe
```

The release binary (smaller, optimized) lands at:
```
apps/tray/src-tauri/target/release/coriven-tray.exe
```

`npm run tray:build` (via `tauri build`) produces a full Windows installer (NSIS/MSI) under `apps/tray/src-tauri/target/release/bundle/`.

---

## Running the unsigned binary

1. Navigate to `apps/tray/src-tauri/target/debug/` (or `release/`)
2. Double-click `coriven-tray.exe`

### SmartScreen warning (expected for unsigned builds)

Windows Defender SmartScreen will show a warning: **"Windows protected your PC"**.
This is expected for unsigned executables during the validation phase (signing is deferred to Epic 8 / Productization).

**To dismiss (one-time):**
1. Click **"More info"**
2. Click **"Run anyway"**

This dismissal is per-machine and per-binary hash; it resets when the binary changes.

> Signing infrastructure (code-signing certificate, notarization for Mac) is out of scope until Epic 8. See ADR-014.

## Tray behavior

| Action | Result |
|--------|--------|
| App launches | Tray icon appears; no window opens; no taskbar entry |
| Right-click tray icon | Menu appears: **Open App**, **Snooze All**, **Quit** |
| **Open App** | Default browser opens at the configured Coriven web app URL |
| **Snooze All** | Visible but inert (placeholder — wired to backend in wave 6.2) |
| **Quit** | App exits cleanly; tray icon disappears; no orphan process |

## Icons

The `src-tauri/icons/` directory contains **placeholder icons** generated by `gen_icons.py` (a teal circle with a 'C' arc). Replace with the final Coriven brand assets before release or at the end of Epic 6.

Required icon files:
- `icon.png` (512×512, main icon)
- `128x128.png`
- `128x128@2x.png` (256×256 for HiDPI)
- `32x32.png` (used as tray icon in debug builds)
- `icon.ico` (Windows ICO, multi-size: 16/32/48/256)

To regenerate placeholders: `python3 apps/tray/gen_icons.py` (requires Pillow).
